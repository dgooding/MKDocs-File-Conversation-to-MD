What PDF fidelity includes

      
    
        
  • Images — extracted from the PDF and saved next to the Markdown
    • 
        
  • Bold / italic / code — from PDF font flags and font names
    • 
        
  • Colored text — via <span style="color:…">
    • 
        
  • Headings — inferred from font size vs body text
    • 
        
  • Page markers — multi-page PDFs get “Page N” sections
    • 
      

      

        Absolute pixel-perfect layout (multi-column floats, decorative vectors) is not
        representable in Markdown. Content fidelity is optimized for a clean MkDocs page.
